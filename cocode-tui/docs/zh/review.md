# 代码 Review

[中文](./review.md) · [English](../en/review.md)

`/review` 用于在当前 Git 工作区中发起只读代码 Review。TUI 不会修改文件、暂存改动或创建提交。

## Review 范围

| 命令                   | 范围                       |
| ---------------------- | -------------------------- |
| `/review`              | 打开范围选择器             |
| `/review working-tree` | 未暂存和已暂存的本地改动   |
| `/review staged`       | 已暂存改动                 |
| `/review last-commit`  | 最近一次提交               |
| `/review branch`       | 当前分支相对基线分支的改动 |

选择范围后，界面会显示文件数量、增删行和受限的 Diff 预览。二进制文件、超大文件和被截断内容会明确标记。确认后，Review 上下文进入当前 session，结果仍作为普通助手消息保存。

Review 输出要求按严重级别列出文件、行号、问题、原因和建议。没有发现问题时应明确说明，而不是生成占位意见。

## 安全限制

- Git 命令使用只读参数，不经过 shell。
- Diff 有大小上限，避免大仓库占满终端或上下文。
- 非 Git 目录、找不到基线分支或 Git 执行失败时只显示错误，不影响普通对话。
